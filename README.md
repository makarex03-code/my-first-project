## 🚀 Deployment (GitHub Pages)
1. Push this repo to GitHub
2. Go to **Settings → Pages**
3. Set source to **Deploy from a branch → main → / (root)**
4. Your site will be live at `https://<your-username>.github.io/my-first-project/`
